# 🎯 Dagens Fokus

En enkel och snygg fokus-app byggd med **HTML, CSS och JavaScript**.  
Perfekt som hobbyprojekt i VS Code för att träna på frontend-grunder.

## ✨ Funktioner

- Spara dagens viktigaste uppgift
- Markera uppgift som klar
- Rensa uppgift
- Pomodoro/fokus-timer (25/15/5 min)
- Timer med progress-ring
- Data sparas lokalt med `localStorage`

## 🛠️ Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Kör lokalt

### Alternativ 1: Python
```bash
python3 -m http.server 5500
```
Öppna: `http://localhost:5500/index.html`

### Alternativ 2: npm (om du använder live-server)
```bash
npm install
npm run dev
```
